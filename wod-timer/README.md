# WOD Timer

크로스핏 와드(WOD) 타이머. 유튜브와 같은 16:9 화면을 반으로 나눠 **왼쪽은 타이머, 오른쪽은 오늘의 운동**을 보여줍니다.
서버·설치 없이 `index.html` 파일 하나로 동작합니다.

## 기능

- 타이머 5종: **FOR TIME**(타임캡 선택), **AMRAP**, **EMOM**, **TABATA**(운동/휴식/라운드 설정), **STATION**
- **STATION**: 여러 동작을 한 번에 자동 진행. 동작 수 · 운동(초) · 세트 사이 휴식(초) · 세트 수 · 동작 간 휴식(초)을 설정하면, 동작마다 `운동 → 휴식`을 세트 수만큼 돌고 마지막 세트 뒤에는 "NEXT MOVE"(다음 동작 준비) 휴식이 이어집니다. 기본값은 5동작, 20초 운동 / 30초 휴식 × 3세트, 동작 간 50초(총 13분 20초)
- 시작 전 준비(카운트다운) 시간, 3·2·1 비프음, 단계 전환음
- 오른쪽 운동 칸: 제목·내용을 직접 입력, 글자 자동 맞춤(길게 써도 한 화면에 들어옴)
- **화면 모드(H)**: 컨트롤을 숨기고 16:9 화면만 꽉 채움 → 화면 공유/OBS/유튜브 라이브 캡처용
- **링크 복사**: 운동 내용과 타이머 설정이 담긴 링크 → 다른 기기에서 열면 그대로 불러옴
- 입력한 내용은 브라우저에 자동 저장 / 실행 중에는 화면이 꺼지지 않음(지원 브라우저)

## 단축키

| 키 | 동작 |
| --- | --- |
| Space | 시작 / 일시정지 |
| R | 리셋 |

## 어디서든 접속하게 올리기 (GitHub Pages)

1. 이 폴더를 기본 브랜치에 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, 브랜치와 `/ (root)`를 선택합니다.
3. `https://<계정>.github.io/<저장소>/wod-timer/` 로 접속합니다.

Netlify, Cloudflare Pages 같은 정적 호스팅에 `wod-timer` 폴더를 올려도 됩니다.
